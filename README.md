# 长夜远征：边境回响

作者昵称：荒野与地牢

《长夜远征：边境回响》是一个偏冒险、生存、怪物强化和结构探索的 Fabric 整合包。世界不再只是安静地等你采矿建家：僵尸会变得更多样，敌对生物会携带装备，掠夺者和怪物势力会更有压迫感；同时主世界、下界、末地都会出现更多地牢、遗迹、酒馆、城堡和危险区域。你需要探索、战斗、建设村庄防线，并在越来越复杂的夜晚中活下去。

## 内容方向

- 冒险探索：更多地牢、遗迹、酒馆、城堡和危险区域。
- 生存压力：夜晚更危险，尸潮和怪物强化会推动玩家持续建设防线。
- 怪物强化：僵尸、掠夺者和敌对生物更具威胁，部分怪物会携带装备。
- 结构扩展：主世界、下界、末地都有更多探索目标。
- 交通与战斗：包含飞艇、枪械、炮台等扩展玩法。
